# v0.0.19 视觉差异说明

> 日期：2026-11-21
> 范围：V2EX 2026 年 11 月回复与主题更新相关界面。

## 结论

- 本项目**没有复制** V2EX 官方 HTML、CSS、JS、示意图或截图。
- 七种回复模式使用本项目独立实现的 DOM 结构与样式。
- 官方帮助页确认了模式名称与交互契约，但未提供可合法复现的像素规格；因此颜色、线宽、圆角、间距、动画与移动端紧凑程度均为 **UNVERIFIED**。
- 本报告不宣称“像素完全一致”，只记录可复现的交互与结构验收。

## 已实现结构

| 模式 | 独立实现 | 可访问性 |
|---|---|---|
| 经典平铺 | 保持原楼层顺序，不显示父引用 | 默认模式 |
| 引用条 | 父回复摘要 + 上下文入口 | 文本可读 |
| 角标与预览 | `#N` 角标 + 悬浮/点击预览 | 键盘焦点可打开 |
| 楼中楼 | 子回复在父回复下方缩进展示 | 展开/收起按钮 |
| 树形缩进 | 最多 4 层缩进与左侧层级线 | 展开/收起按钮 |
| 对话连线 | 保持时间顺序，以左侧连线表达父子关系 | hover/焦点高亮 |
| 引用楼层 | 父回复摘要折叠区块 | 原生 `details/summary` |

## 深色模式

- 使用 `data-theme` 保存偏好、`data-effective-theme` 保存有效明暗值。
- 首屏脚本在绘制前应用，减少白屏闪烁。
- 表单、导航、分页、引用、楼中楼、编辑器、图片预览均使用深色适配。
- 图片与头像不应用 CSS 反色滤镜。

## 无法验证项

- 官方示意图选择器的具体外观。
- 官方对话连线的颜色、曲率与重叠处理。
- 官方树形缩进的精确层级上限与移动端缩进。
- 官方引用楼层的长链折叠阈值。
- 真实 Safari 与 Playwright WebKit 之间的像素差异。
