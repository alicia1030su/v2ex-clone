## 二、组件级检查项（任务书要求的 17 项）

任务书明确：**「不能只看整体截图像不像，必须拆分成组件逐项检查。」**

### 2.1 布局（Layout）

| 检查项 | 本站现状 | 对照方法 |
|---|---|---|
| 页面整体宽度 | `.content { max-width: 1060px }`（v0.0.4 已实测） | 量 `#Wrapper` / `.content` 的 `getBoundingClientRect().width` |
| 主内容栏与侧边栏比例 | V2EX 桌面布局右侧栏**固定宽度占位**（实测 1920 视口下主区 770px = 40%） | 量 `#Main` 与右栏的宽度比 |
| 页面留白 | `.content { padding: 0 10px }`（窄屏） | 量 `padding-left/right` 与各区块 `margin` |
| 导航布局 | `#Top` 固定顶栏 | 量 `#Top` 高度、定位方式（fixed/static） |
| 固定元素 | —— | 检查哪些元素 `position: fixed/sticky` |
| 页面滚动行为 | —— | 检查顶栏是否 fixed、是否有 scroll-behavior |

### 2.2 排版（Typography）

| 检查项 | 本站现状 | 对照方法 |
|---|---|---|
| 字体 | `globals.css` 的 `font-family` | 与快照的 `font-family` 比对 |
| 字号 | —— | 逐元素量 `font-size`（正文 / 标题 / 楼层号 / 元信息） |
| 字重 | —— | 逐元素量 `font-weight` |
| 行高 | —— | 逐元素量 `line-height` |
| 文字颜色 | —— | 逐元素量 `color`（正文 / 链接 / 次要信息 / 灰色） |
| 背景颜色 | —— | 逐元素量 `background-color` |

### 2.3 组件（Components）

| 检查项 | 对照方法 |
|---|---|
| 边框和分割线 | 量 `border-width/style/color` + `.sep*` 分隔块高度 |
| 按钮尺寸 | 量 `height/padding/font-size`（主按钮 / 次按钮 / 小按钮） |
| 图标 | 列出图标清单（本站用内联 SVG，原站用雪碧图/字体图标）⇒ **尺寸与语义对照，不复制素材** |
| 图片比例 | 量头像（`img.avatar` 应为正方形）、主题附图 |
| 卡片间距 | 量主题列表项的 `margin/padding`、楼层间距 |
| 悬停效果 | 检查 `:hover` 的 `background/color/border` 变化 |
| 空状态 / 加载 / 错误 | 见 §五 |
