# V2EX 视觉改造记录 v0.0.21

> 基线：`e50f77988bd639823658bfcbe690643bf11d24cb`
> 运行环境：Windows 11 / Node 22.23.4 / Chromium Edge / DPR 1 / zh-CN / light
> 资源守护：所有构建、审计与 E2E 均经 `tools/dev-memory/run.mjs` 串行执行

## 1. 实际改动

### 全局布局与设计令牌

- 新增 `src/app/tokens.css`，统一顶栏、内容宽度、主栏/右栏宽度、gutter、主题行尺寸、元数据与焦点环令牌。
- 主栏保持 770px、右栏 270px、栏间距 20px；修复首轮 token 化时少算一个 gutter 导致主栏扩大到 790px 并贴住右栏的回归。
- 全局链接色从 `#778087` 调整为 `#6b747b`，白底对比度 4.76:1。
- 增加统一 `:focus-visible` 焦点环。

### 首页与主题列表

- 主题行垂直 padding 10→8px，标题 16→15px，元数据行高 200%→150%。
- 桌面主题行实测 71→65px，信息密度提升但不压缩可读性。
- 元数据从过淡的 `#ccc` 改为 `#757575`，白底对比度 4.61:1。
- 主题行增加轻微 hover 背景。
- 回复数徽章底色加深，白字对比度 5.39:1。

### 移动端

- 手机主题头像列固定 32px，标题 14px、元数据 11px。
- 保持 375/390px 无横向溢出，右栏在主栏之后正常堆叠。

### 导航与搜索

- 登录、注册、设置、发布主题、重置密码与静态页的 7 处裸搜索 input 统一替换为可交互 `SearchBox`。
- 搜索 input 增加可访问名称，建议列表与提交行为与其他页面一致。

### 表单与交互

- 登录、注册、找回密码、设置、分页跳转、回复图片上传补充 `aria-label`。
- 后台/通知 tab 去掉浏览器默认灰底，改为透明底，消除 4.18:1 的按钮对比度问题。
- 节点头部深色区域链接改为浅色，保证可读性。
- 审计器正确识别带 `img[alt]` 的头像链接和带 `aria-label` 的 RSS SVG，避免把可访问图标误判为空链接。

### 审计器

- 增加 `before/after` 阶段参数，after 不覆盖 before 证据。
- 矩阵校验同时校验 before/after 文件哈希与 `collection-error`。
- 修正 Playwright `page.evaluate` 多参数错误、移动端上下布局误判重叠、失败页透明 PNG 假证据。
- fixture 每次执行完整幂等迁移并校验 journal；为既有 seed 图片引用补项目自有确定性占位图。
- after 覆盖七种回复模式：classic/quote/badge/nested/tree/lines/excerpt，guest/user 各 7 种。
