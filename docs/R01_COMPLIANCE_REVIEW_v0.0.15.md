## 四、PR refs 与缓存可达性

| 项 | 事实 |
|---|---|
| 可达的 PR ref | **8 个**：`refs/pull/1/head` ~ `refs/pull/8/head` |
| 为什么合并后仍可达 | GitHub **不删除**已合并 PR 的 head ref；它永久挂在 `refs/pull/N/head` 下 |

## 八、已发布版本的恢复 / 迁移方案

清理并 force push 后，已发布 Tag 的 SHA 会变。需要决定如何处理**已发布的 Release**：

| 方案 | 做法 | 代价 | 合规效果 |
|---|---|---|---|
| **R1 重建 Tag + 保留 Release** | 用新 SHA 重建 Tag，Release 内容不动 | Release 与 Tag 的关联需重建；下载 URL 的 tag 路径变了但资产不变 | 素材不可达（除 PR ref / 缓存） |
| **R2 重建 Tag + 重建 Release** | 连 Release 一起重建（新 id、新 URL） | 破坏所有已发布的下载链接与外部引用 | 同上 |
| **R3 保留旧 Tag（不动）+ 只清理分支** | 仅改写 `refs/heads/*` | **素材仍从 4 个 Tag 可达 ⇒ 基本无效** | ❌ 无效 |
| **R4 删除仓库重建** | 全新仓库，只导入当前树 | 丢失全部 Issue / PR / Release / Star / Watch；**旧仓库仍可被 fork 保留** | 最彻底但代价最大 |

**本轮不推荐任何一项** —— 这是主人的决策。但可以指出技术事实：
- R1 的代价最小（资产不变、链接基本不变），但需重建 4 个已发布 Tag；
- R3 **无效**（本轮实测：Tag 仍让素材可达）；
- R4 也无法消除已 fork 的副本。

## 十、保留当前仓库 vs 迁移到干净仓库

| 维度 | A. 保留 + 改写历史 | B. 迁移到全新仓库 |
|---|---|---|
| 素材可达性 | PR ref / 缓存仍可达（除非 Support 介入） | 新仓库完全干净；**旧仓库仍存在** |
| Issue / PR 历史 | 保留 | **全丢** |
| Star / Watch / Fork | 保留 | **全丢** |
| Release 资产 | 可保留（R1） | 需重新发布（新 URL） |
| 已发布下载链接 | 基本不变（R1） | **全部失效** |
| 旧仓库处置 | — | 需删除或归档（**旧仓库的 fork 仍在**） |
| 操作可逆性 | **不可逆**（force push 后旧对象会被 GC） | 旧仓库不删则**可逆** |
| 实施复杂度 | 中（9 个 Tag 重写 + 4 个 Release 重建） | 高（重建 CI / Secrets / Packages / 社区） |

**技术判断**：若目标是「尽最大努力切断未来可达性」且能接受 PR ref 残留，
选 **A（最小清理 + R1）**；若目标是「彻底切割」，需 **B + 删除旧仓库**，
但那会丢失全部社区资产，且**已 fork 的副本不受影响**。

## 十一、无法撤回的风险（必须如实说明）

以下内容**任何技术手段都无法撤回**，清理只能降低「未来可达性」：

| 项 | 为什么无法撤回 |
|---|---|
| 已克隆的仓库副本 | Git 是分布式版本控制；任何 clone 都持有完整对象库 |
| 已 fork 的仓库 | fork 的对象库独立，源仓库改写不影响它 |
| `raw.githubusercontent.com` 的 CDN 缓存 | 由 GitHub / 第三方 CDN 控制，仓库方无权清除 |
| 搜索引擎索引与快照 | 第三方服务，且可能有网页快照 |
| 第三方镜像站 / 代码搜索服务 | 完全不受仓库方控制 |
| 已下载的 ZIP / 镜像 | 一旦落到用户磁盘即无法撤回 |
| Actions run 日志中残留的路径名 | 日志保留期由 GitHub 决定，仓库方不能逐条删除 |

⇒ **清理的价值是「降低未来可达性」，不是「消除已发生的暴露」。**
把它描述成「已经清除」是不准确的。

## 十二、法律咨询建议（**技术清理 ≠ 获得版权授权**）

本节**不是法律意见**，只是提示该问律师什么：

1. **技术清理与法律责任是两件事。** 改写历史不会让「曾经未经授权复制并公开分发」这件事消失，
   也不产生任何使用许可。
2. 建议向律师确认：
   - 就「早期开发阶段的界面还原研究」这一用途，是否存在可主张的合理使用 / 转换性使用空间；
   - 已停止分发并主动清理后，实际法律风险的变化幅度；
